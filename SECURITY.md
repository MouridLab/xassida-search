# Politique de sécurité

Ne publiez pas de vulnérabilité dans une issue publique. Utilisez les avis de sécurité privés du dépôt GitHub ou contactez les mainteneurs de MouridLab par un canal privé vérifié.

Indiquez le composant concerné, l’impact, les conditions de reproduction et une proposition de correction si elle existe. N’incluez jamais de token, mot de passe, clé Supabase, URL PostgreSQL ou identifiant MinIO réel.

Seule la dernière version de la branche `main` est prise en charge. Les signalements légitimes seront accusés réception dès que possible, puis traités selon leur sévérité.
