# Xassida Search — V1

Prototype statique d’un moteur de recherche dédié aux khassaïdes de Cheikh Ahmadou Bamba.

## Lancer le projet

Ouvrez simplement `index.html` dans votre navigateur.

Pour un serveur local :

```bash
python -m http.server 8000
```

Puis ouvrez `http://localhost:8000`.

## Contenu

- Recherche instantanée
- Variantes orthographiques simples
- Filtres PDF, audio et texte arabe
- Interface responsive
- Fiches de démonstration
- Fenêtre de détails

## Important

Les textes, traductions, métadonnées, PDF et audios définitifs devront être vérifiés et validés avant mise en ligne.
